**A web flow's browser can stay open between runs.** A browser flowproof launched always closed with its run, so running a flow from its middle started over at `url:`. `run --leave-open <file>` now leaves a visible browser open when the run ends, recorded in a private session file (DevTools bound to 127.0.0.1, file `chmod 600` and refused otherwise); `run --attach <file>` carries on in it from the page it is on, without opening `url:` or applying `session:`; and `flowproof session close <file>` closes it and removes its profile. The kept browser runs in its own process group, so stopping a run does not take it down.
