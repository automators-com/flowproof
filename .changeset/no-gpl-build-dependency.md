**No GPL code in the build any more.** headless_chrome, which flowproof uses to drive the user's installed Chrome for web flows, generated its Chrome DevTools Protocol bindings at build time with auto_generate_cdp, a GPL-3.0-or-later tool. The patched copy flowproof builds from now commits those bindings instead: the same code, generated once from the same protocol files. auto_generate_cdp and six crates only it used are gone from the dependency tree, and the new cargo-deny licence check keeps GPL out.
