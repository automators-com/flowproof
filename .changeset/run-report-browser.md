**A web run's `result.json` now says which browser it ran in.** Auto-detection picks Chrome, then Chromium, then Edge, and `CHROME` can point anywhere, so two machines running the same flow can drive different browsers without either run saying so. A replay that behaved differently on an Edge-only Windows box looked identical in its report to one on Chrome. Web runs now carry `browser: {name, version}`, naming the product from the executable rather than from `getVersion`, which calls every Chromium "Chrome", and giving Edge its own version rather than the Chromium one it is built on. Runs that drove no browser omit the field, so existing readers are unaffected.
