**flowproof is installable as a Claude Code plugin.** `/plugin install
flowproof --marketplace automators-com/flowproof` registers `flowproof mcp`
and the `flowproof-flows` and `flowproof-config` skills for every project at
once, instead of running `flowproof mcp install` in each. It runs the
`flowproof` command, so install flowproof globally first.
