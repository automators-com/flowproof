**Vision reads and fills table cells on a host terminal screen.** A mainframe screen over Citrix is a character grid whose tables are header lines over rows of input fields, and OCR reads such a table as column blocks - a value lost the row it belonged to, `XB30` beside `1` read as `2XB30`, and the cell grammar every other surface understands (`the "Stufe" column of the row containing "002"`) was silently ignored by vision, failing as "not found". Vision now finds the cell on the grid - the row by its anchor, the column from its header to the next, under the nearest header above - and reads only that box, closer. Typing into a cell clicks its first character and deletes once per character before typing, because a terminal field has no select-all and typing overwrites: `A12` typed over `Q089` used to leave `A129`.

**Small text is read enlarged as well.** A terminal's thin 9px Courier read `XE30` for `XB30` and `Ahgabe` for `Abgabe`: OCR loses the strokes that tell letters apart on text that small. When a screen's text measures under 12px, vision also reads it enlarged with Windows OCR, and that reading leads; what the screen-size reading found stays matchable behind it, and screens of ordinary text are read once as before.
