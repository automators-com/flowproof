**Vision reads and fills table cells on a host terminal screen.** A mainframe screen over Citrix is a character grid whose tables are header lines over rows of input fields, and OCR reads such a table as column blocks - a value lost the row it belonged to, `ZB30` beside `1` read as `2ZB30`, and the cell grammar every other surface understands (`the "Tarif" column of the row containing "002"`) was silently ignored by vision, failing as "not found". Vision now finds the cell on the grid - the row by its anchor, the column from its header to the next, under the nearest header above - and reads only that box, closer. Typing into a cell clicks its first character and deletes once per character before typing, because a terminal field has no select-all and typing overwrites: `A12` typed over `K089` used to leave `A129`.
