**`flowproof run --from N --until M` replays part of a flow.** Testers write a flow a few steps at a time, and every run replayed it from the first step. `--from` and `--until` pick the spec steps to run, counted the way the file reads; the rest are reported skipped, `not selected`, and the report carries a `selection` field (also a `flowproof.selection` property in `junit.xml`) so a partial pass is never read as a full one. The run is refused before launch when the range is outside the flow, recorded nothing, or a selected step reads a capture an unselected step makes. A partial run writes no audit run record.
