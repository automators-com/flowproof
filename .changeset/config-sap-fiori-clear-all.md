**`flowproof config sap`/`config fiori` can now clear a whole profile in one call.** #669 added per-field `--clear-*` flags, but decommissioning a profile entirely still meant five separate calls. `--clear-all` now removes the whole `sap:`/`fiori:` block from `config.yaml` in one shot, and — like every other clear flag — is rejected if combined with any other flag on the same command.
