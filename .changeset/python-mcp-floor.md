**`pip install flowproof[mcp]` no longer accepts an `mcp` with known security advisories.** The extra asked for `mcp>=1.2`, so an install could resolve to a release whose server accepted bearer tokens issued for a different resource server, or whose HTTP client carried custom headers across a cross-origin redirect. It now asks for `mcp>=1.30,<2`. 1.30.0 fixes those, and the cap keeps a future 2.x, which the SDK has not been tested against, from arriving unannounced.
