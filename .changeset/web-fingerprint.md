**Web recordings now say what each target was.** A web step recorded its selector and nothing else, so `#make` looked the same in a trace whether it was a dropdown or a text box, and a page's title was known only if a step asserted it. The web adapter now fills `observed.fingerprint` for every plain target: the tag and input type or role, the `name` attribute, the label (a form control's `<label>`, its accessible name or placeholder, or a button's or link's own text), the page title and the origin. It never reads an input's value, a textarea's content or a select's options, so a trace gains a description of the page, not its data. Existing traces are unchanged until re-recorded.
