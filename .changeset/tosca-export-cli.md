**`flowproof export` hands a SAP GUI or web recording to Tosca.** The Tosca mapping had no command, and it covered SAP only. `flowproof export --format tosca-json` now writes the migrator's test-case JSON from a trace or a flow spec, with warnings on stderr so stdout stays a clean document. Web traces export too: the flow's URL becomes `NavigateBrowser`, and a target with a DOM id becomes an `html id` element; a target without one is named as a warning, since Tosca would have nothing stable to find it by.
