**`flowproof config sap`/`config fiori` can now clear a stored field, not just set one.** Both commands had every setter flag (`--user`, `--password`, `--client`, `--language`, `--connection`/`--base-url`) but no way to unset one once stored — `config ai` already had `--clear-*` flags for exactly this, so a terminal-only setup (CI, a headless machine) had no way to decommission a SAP or Fiori password short of hand-editing `config.yaml`. Each field now has a matching `--clear-*` flag, and pairing one with its own setter is rejected outright, the same posture `config ai`'s clear flags already took.
