**A machine with Edge but no Chrome can run web flows again.** Browser auto-detection on Windows looked for Edge in exactly one folder, `Program Files (x86)`, so an Edge installed anywhere else, a per-user Chrome or Edge, or Brave, came back as "Could not auto detect a chrome executable" while a drivable browser sat on disk; the only way through was knowing to set `CHROME` by hand. flowproof now also checks both Program Files folders and `%LOCALAPPDATA%` on Windows, `~/Applications` on macOS, and Brave everywhere. When nothing is found, the error says `no supported browser found`, names Chrome and Edge as the fix and `CHROME` as the override, and says why Safari and Firefox won't do. A `CHROME` that points at a missing file is now reported as such instead of surfacing as an opaque launch failure.
