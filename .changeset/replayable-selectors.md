**A recorded web step no longer depends on an id the page mints on each load, or on a field being focused.** Recording a field by an id such as `user-widget-location-6af44f6a60bf3` (a PHP uniqid, a UUID, a timestamp, React's `useId`) wrote a selector that matched nothing on the next load. Such ids are now skipped and the field is addressed the way an element without an id already is. And a field inside a dialog marked `aria-hidden="true"` showed in Chrome's accessibility tree only while it had focus, which is exactly when recording reads it, so its accessibility selector could never be replayed; that hint is no longer recorded. Together they made a recorded price calculator on Stadtwerke Flensburg's site fail on replay with "element did not appear".
