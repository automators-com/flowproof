**A SAP GUI trace can now be mapped to Tosca.** `flowproof_trace::tosca::export` turns a recorded SAP trace into the test-case JSON the Automators Tosca migrator imports, so a flow recorded once no longer has to be rewritten by hand to live in a Tosca suite. Transactions become `StartTransaction`, scripting ids become `RelativeId`, checks become `Verify` or `Exist`, and a step Tosca cannot express, such as a page-wide text check, is returned as a warning instead of being dropped. The `flowproof export` command that exposes it follows.
