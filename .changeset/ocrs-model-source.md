**Vision starts on a fresh machine again.** The ocrs OCR models were downloaded from the S3 bucket ocrs first published to, which now answers 403 to everyone: any machine that had never run a vision flow - a new laptop, a CI runner, a client's PC set up for Citrix - failed at the first step, told to place a file it had no way to get. Machines that downloaded the models earlier kept working from their cache, which hid it. The models now come from the ocrs author's Hugging Face repository, pinned to a commit so the bytes cannot change under a cached install, and an existing cache keeps working unchanged.
